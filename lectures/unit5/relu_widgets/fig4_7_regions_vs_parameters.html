a) One input (Di = 1)

Each curve fixes the number of hidden layers K and varies the width D

b) Ten inputs (Di = 10)

Each point along a curve adds ten hidden units per layer

For a fixed parameter budget (horizontal position), deeper networks can produce far more linear regions. With one input, a network with K layers of D hidden units has at most (D + 1)K regions and 3D + 1 + (K − 1)D(D + 1) parameters. The highlighted point in (a) is K = 5, D = 10: 471 parameters and 161,051 regions. In (b), K = 5, D = 50 has 10,801 parameters and more than 1040 regions.

Region counts are the maximum achievable: (⌊D/Di⌋ + 1)Di(K−1) · Σj=0…Di C(D, j), which reduces to (D + 1)K when Di = 1 (Montúfar et al., 2014). One output throughout.
