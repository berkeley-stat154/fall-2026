Lab 7 Exercise - Proxy Losses, Logistic Regression and ROC Curves

Author

Josh Davis/Lucas Schwengber

Learning goals

By the end of this lab you should be able to:

  1. State the Bayes classifier for a weighted zero-one loss: predict 1 when \(p(\boldsymbol{x}) = \mathbb{P}_{\,}\left(y = 1 \mid \boldsymbol{x}\right) > c_{\text{FP}} / (c_{\text{FP}} + c_{\text{FN}})\).
  2. Explain why we minimize a proxy loss instead of the zero-one loss.
  3. Explain why proxy losses such as the log loss are minimized by \(p(\boldsymbol{x}) = \mathbb{E}_{\vphantom{}}\left[y \mid \boldsymbol{x}\right]\), and that logistic regression is ERM with the log loss.
  4. Explain how LDA estimates \(p(\boldsymbol{x})\) generatively, and when it differs from logistic regression.
  5. Choose a threshold from the costs of the two kinds of mistakes.
  6. Use an ROC curve to detect a classifier that looks accurate but ignores a rare class.

As in Lab 4, you work in simulated practice worlds with two features, where we know the true probability \(p(\boldsymbol{x})\). PracticeWorld(scenario, prior=0.5) creates a world in which \(\mathbb{P}_{\,}\left(y = 1\right)\) equals prior:

If world = PracticeWorld(...), then world.simulate(n, seed) draws X, y; world.true_prob(X) gives \(p(\boldsymbol{x})\); world.true_risk(model) gives the true log loss of a fitted model (loss="error" for its misclassification rate); world.bayes_risk() gives the smallest possible risk; and world.plot_true_boundary(ax, level=0.5) draws \(\{\boldsymbol{x}: p(\boldsymbol{x}) = \text{level}\}\) on a plot of the two features.

To draw where a fitted model’s probability equals t, use DecisionBoundaryDisplay.from_estimator(model, X, response_method="predict_proba", plot_method="contour", levels=[t], ax=ax).

2 Logistic regression vs. LDA

LDA assumes each class is Gaussian with a common covariance and applies Bayes’ rule. Its log odds are linear, exactly like logistic regression, but its coefficients come from the class proportions, class means and pooled covariance rather than from minimizing the log loss (ESL Section 4.4.5).

3 Thresholds and costs

Suppose class 1 is a disease affecting 10% of patients, and a false negative costs 9 times as much as a false positive: \(c_{\text{FN}} = 9\), \(c_{\text{FP}} = 1\). The average cost of a classifier on \(N\) observations is \((c_{\text{FP}} \cdot \text{FP} + c_{\text{FN}} \cdot \text{FN}) / N\), and the Bayes classifier predicts 1 when \(p(\boldsymbol{x}) > c_{\text{FP}} / (c_{\text{FP}} + c_{\text{FN}})\) (Homework 2, Problem 1). The threshold of \(\mathrm{I}\left(q(\boldsymbol{x}) > t\right)\) is a hyperparameter, so we choose it with CV.

LLM usage policy

You may use auto-completion for filling out small code snippets (affect around 2-3 lines of code) and documenting your code. Small code snippets are things like “add a label for the axis of the plot”, “change the color of the points”, “add an argument for the number of interactions in the fit”. These are small code operations which do not involve significant planning nor automated changes to the logic of the code without your supervision. All edits must be verified and accepted manually, and you should make sure you know what the code is doing.

Things that are explicitly not allowed are major edits to the code (affect > 10 lines) and ones which involve automating huge parts of the development of the logic structure of your analysis. For example, “write a function to extract features from the data”, or “run a test set validation loop and report the best model”.
